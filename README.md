# MY WORLD — 2D 온라인 메타버스 시작 프로젝트

## 포함된 기능
- 브라우저에서 실행되는 2D 초원 맵
- WASD/방향키 캐릭터 이동
- Socket.IO를 이용한 실시간 사용자 이동 동기화
- 이름 변경과 월드 채팅
- 접속/퇴장 표시
- 모바일 화면을 고려한 레이아웃(이동은 키보드 기준)

## 로컬 실행
1. Node.js 18 이상 설치: https://nodejs.org/
2. 이 폴더에서 터미널 실행
3. `npm install`
4. `npm start`
5. 브라우저에서 `http://localhost:3000` 접속

같은 와이파이의 다른 기기에서 테스트하려면 컴퓨터의 로컬 IP와 3000 포트를 이용할 수 있습니다. 방화벽 설정이 필요할 수 있습니다.

## 인터넷에 공개하기 (Render 예시)
1. 이 폴더의 파일을 GitHub 저장소에 업로드합니다.
2. Render에서 새 Web Service를 만들고 저장소를 연결합니다.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. 배포가 끝나면 Render가 제공하는 공개 URL로 접속합니다.

배포 서비스의 무료 요금제·제한·가격은 바뀔 수 있으므로 배포 시 공식 안내를 확인하세요.

## 운영 전 확인
이 프로젝트는 시작용 시제품입니다. 공개 운영 전에는 채팅 신고/차단, 속도 제한, 사용자 행동 검증, 개인정보 안내, 서비스 약관, 접근성 및 보안 검토를 추가하세요. 현재는 계정/비밀번호 기능이 없습니다. 외부 CDN의 Phaser 라이브러리를 사용합니다.
